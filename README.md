* Cursando el 7.º semestre de Ingeniería Informática en el Instituto Tecnológico Superior de Zacapoaxtla.

### Proyectos Destacados

* **Monitoreo de Patrullaje (Seguridad Pública de Tlatlauquitepec):** Aplicación móvil nativa en Kotlin con ubicación GPS en tiempo real, conectada a Firebase Firestore y con guardado local de datos para zonas sin señal.
* **Sistema de Hechos de Tránsito:** Aplicación móvil en Kotlin conectada a un panel web en PHP y Bootstrap para digitalizar y agilizar el registro de reportes viales.
* **Análisis y Modelado de Datos:** Limpieza de datos en Power Query, diseño de modelos relacionales y creación de reportes interactivos en Power BI usando SQL.
* **Infraestructura de Redes y Servidores:** Configuración y administración de servicios de red (DHCP, DNS, FTP, Proxy) en entornos Ubuntu Server y despliegue en Windows Server.
* **Estacionamiento Inteligente (IoT):** Control de acceso vehicular con tarjeta ESP32, sensores ultrasónicos y servomotores programados en Python y C/C++.
